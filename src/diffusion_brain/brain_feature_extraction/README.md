# Majaj2015 Dataset Feature Extraction

This code is adapted from [SNAP](https://github.com/chung-neuroai-lab/SNAP/tree/main) to save neural activations, as well as extract and save different model internal representations on the same dataset.

To install the requirements, run:

```bash
pip install .
```

To save the activations, follow the `get_brain_data.ipynb` and `get_model_activations.ipynb` notebooks.
